Rootly Private Agent {{ .Chart.AppVersion }} has been installed.

This chart is an early preview. The agent opens outbound connections only; no
Service or Ingress is created.

Check its status:

  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "rootly-private-agent.fullname" . }}

For the in-cluster provider, the chart grants read-only access to the documented
Kubernetes resources. Pod logs remain disabled unless
providers.kubernetes[].policy.allowPodLogs is true. Secrets and workload
mutation permissions are never granted. To disable Kubernetes entirely, set
providers.kubernetes=[] and rbac.create=false.
